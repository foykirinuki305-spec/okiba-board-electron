# OkibaBoard（Electron版）

フォルダをデスクトップみたいに使える、シンプルなボードアプリです。
承認されたデザイン案に合わせて、見た目をウェブサイトと同じ技術（Electron）で作り直した版です。機能とデータ形式は Tk 版 v7 と互換です。

## 使い方

1. `OkibaBoard-Setup-2.0.0.exe` を実行してインストールします（管理者権限は不要です）。
2. デスクトップにできる **OkibaBoard のアイコン** から起動します（スタートメニューにも入ります）。インストール版は起動のたびの自己展開がないので、ポータブル版より速く立ち上がります。
3. ホーム画面にボードが並びます。「＋ ボード」で名前を付けて増やせます。
4. ボードを開くと、中の素材がデスクトップ式のアイコンで並びます。

※ 予備として、インストール不要のポータブル版 `OkibaBoard.exe` も従来どおり使えます。

## 素材の場所について（v2.0 の大事な変更）

**ボードに入れても、ファイルは元の場所のままです。** ボードは元の場所への参照（リンク）だけを覚えます。代わりに、ボードに入れた素材には「隠しファイル」の印が付き、**デスクトップやエクスプローラーからは見た目だけいなくなります**。場所（パス）は変わらないので、**AviUtl の参照は切れません**。ボードから外すと印が外れて、また元の場所に見えるようになります。

- 元からボードのフォルダー（`C:\OkibaBoards`）の中にある素材は、そのまま実ファイルとして扱われます（従来どおり）。2つの種類が1つのボードに混ざって問題ありません。
- リンク中の素材が、ボードの外で移動・削除されると、カードは灰色になって「元の場所にありません」と表示されます（勝手に消えたりはしません）。右クリックの「ボードから外す」で片付けられます。

## できること

- **ボードは実フォルダ**: 保存先は `C:\OkibaBoards`。ボード名 = フォルダ名です。右クリックで名前変更 / 場所を開く / ゴミ箱へ削除。ボードを消しても、リンク中の素材の実ファイルは無事です（隠し印だけ外れます）。
- **配置はデスクトップ式**: グリッドにピチッと吸着、縦の列から先に埋まります。ドラッグで動かすと位置が保存され、埋まっているマスに落とすと入れ替わります。
- **複数選択**: ボードの空き地をドラッグすると青い囲い（ラバーバンド）が出て、囲いに入ったアイテムをまとめて選べます（Ctrl+クリックでの追加選択も使えます）。選んだアイテムはまとめてドラッグで動かせます。誰かのマスに重なる場合は、全部元の位置に戻ります。
- **入れ方**: エクスプローラーからファイルをドラッグ＆ドロップ。ファイルは移動もコピーもされず、リンクとして登録されて、その場で見た目だけ隠れます。同じ素材を同じボードに2回入れても1件だけになります。
- **出し方（リンク素材）**: 窓の外へドラッグして離すか、右クリックの「ボードから外す」で、ボードから外れます。**ファイル自体はどこへも動きません**（元の場所でまた見えるようになります）。
- **出し方（ボード内蔵の素材）**: アイコン（複数選択中は全部）を窓の外へドラッグして、**デスクトップやエクスプローラーのフォルダーの上で離すと、そこへ「移動」します**。離した場所の下にあるフォルダーをアプリが判定して、実ファイルを移動します。タスクバーや他のアプリの上など、場所が判定できないところで離した場合は何も起きません（元の位置に戻り、画面下にメッセージが出ます）。確実に移動したいときは、右クリックの「デスクトップへ移動」もあります。デスクトップへ落としたときは、落とした位置にアイコンを置きます。ただしデスクトップの「アイコンの自動整列」がオンだと位置は合いません。位置を合わせられなかったときは理由が画面下にメッセージで出ます（詳しい記録は C:\OkibaBoards\okiba.log に残ります）。
- **右クリックメニュー**:
  - ボード内蔵の素材: 開く / 名前を変更 / 場所を開く / デスクトップへ移動 / ゴミ箱へ削除。
  - リンク素材: 開く / 名前を変更（※名前を変えると AviUtl 等の参照が切れるので、確認の注意書きが出ます）/ 場所を開く / **ボードから外す**（実ファイルは無事）/ **ファイルをゴミ箱へ削除**（実ファイル自体を消す、明示的な操作）。
  - 複数選択中は件数表示と、まとめて「選択をボードから出す」（リンク素材は外す、内蔵素材はデスクトップへ移動）/「ゴミ箱へ削除（実ファイルも削除）」。
- **大きさ**: 「大きさ」の一覧から 25〜125% を選べます（小さい側が細かい刻みです）。ボードごとに保存されます。
- **テーマ**: 紺（標準）/ 黒グレー / 深緑 / 紫夜 / 焦げ茶 の5つ、全部ダーク系です。
- **外での変更も反映**: エクスプローラーで出し入れすると、監視＋定期チェック＋画面に戻った時の再読み込みでボードに反映されます。
- Tk 版で作ったメモもそのまま表示され、編集・削除できます（新規追加ボタンはありません）。

## アップデート方法

**新しい Setup を実行するだけ**です。ボードの中身・配置はプログラムの外（`C:\OkibaBoards` と、リンク素材の元の場所）に保存されているので、そのまま引き継がれます。ポータブル版の場合は exe を取り替えるだけです。古い版の保存先（ドキュメントの `OkibaBoards`）にボードが残っている場合は、起動時に自動で合流します（上書きはしません）。アンインストールしてもボードの中身は消えません。

## 注意

- 署名していない exe なので、初回起動時に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- 「隠しファイル」の印は、エクスプローラーの「隠しファイルを表示」が **オフ**（Windows の初期設定）のときだけ見た目を隠せます。オンにしている場合は、素材が半透明で表示されます（アプリ側では切り替えられません）。
- 検証について: ビルドとファイル操作ロジック、起動確認、画面操作（ボード作成・ドラッグ移動・複数選択・グループ移動・％変更・テーマ変更・再起動復元・リンク登録/解除/リンク切れ表示）は GitHub Actions の実 Windows 環境で自動テストしています。隠し印の付け外しも実 Windows 上で本物の `attrib` を使って確認しています。インストーラーも、無人で「サイレントインストール → インストールした exe の起動確認 → アンインストール（データが消えないこと）」まで自動検証しています。外への移動も、判定先フォルダーを差し替えた GUI テストで「外で離す→実ファイルが移動する」ところまで自動確認しています。ただし、落とした場所の判定は Windows のシェル（デスクトップ / エクスプローラーのウィンドウ）を読む処理なので、実際の判定がお使いの PC で正しく働くかは、一度ドラッグアウトを試してご確認ください。

## 開発

- ロジック単体テスト: `node tools/selftest.js`
- ビルド: GitHub Actions（windows-latest）がポータブル版 `OkibaBoard.exe` を生成します。
