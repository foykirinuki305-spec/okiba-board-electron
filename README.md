# OkibaBoard（Electron版）

フォルダをデスクトップみたいに使える、シンプルなボードアプリです。
承認されたデザイン案に合わせて、見た目をウェブサイトと同じ技術（Electron）で作り直した版です。機能とデータ形式は Tk 版 v7 と互換です。

## 使い方

1. `OkibaBoard.exe` をダブルクリックで起動します（インストール不要のポータブル版）。
2. ホーム画面にボードが並びます。「＋ ボード」で名前を付けて増やせます。
3. ボードを開くと、中の実ファイルがデスクトップ式のアイコンで並びます。

## できること

- **ボードは実フォルダ**: 保存先は `C:\OkibaBoards`。ボード名 = フォルダ名です。右クリックで名前変更 / 場所を開く / ゴミ箱へ削除。
- **配置はデスクトップ式**: グリッドにピチッと吸着、縦の列から先に埋まります。ドラッグで動かすと位置が保存され、埋まっているマスに落とすと入れ替わります。
- **入れ方**: エクスプローラーからファイルをドラッグ＆ドロップ（同じドライブは移動、別のドライブはコピー、上書きはせず「 (2)」を付けます）。
- **出し方**: アイコンを窓の外へドラッグすると、Electron 公式のネイティブドラッグで実ファイルが渡ります。確実な方法として右クリックの「デスクトップへ移動」もあります。
- **右クリックメニュー**: 開く / 名前を変更 / 場所を開く / デスクトップへ移動 / ゴミ箱へ削除（ゴミ箱は Windows のゴミ箱行きです）。
- **大きさ**: 「大きさ」の一覧から 25〜125% を選べます（小さい側が細かい刻みです）。ボードごとに保存されます。
- **テーマ**: 紺（標準）/ 黒グレー / 深緑 / 紫夜 / 焦げ茶 の5つ、全部ダーク系です。
- **外での変更も反映**: エクスプローラーで出し入れすると、監視＋定期チェック＋画面に戻った時の再読み込みでボードに反映されます。
- Tk 版で作ったメモもそのまま表示され、編集・削除できます（新規追加ボタンはありません）。

## アップデート方法

**exe を取り替えるだけ**です。ボードの中身は exe の外（`C:\OkibaBoards`）に保存されているので、そのまま引き継がれます。古い版の保存先（ドキュメントの `OkibaBoards`）にボードが残っている場合は、起動時に自動で合流します（上書きはしません）。

## 注意

- 署名していない exe なので、初回起動時に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- 検証について: ビルドとファイル操作ロジック、起動確認は GitHub Actions の実 Windows 環境で自動テストしています。一方で、画面上でのドラッグアウト／ドラッグインの実際の手触りと、最終的な見た目の細部は実機でしか確認できないため、お使いの PC で一度ご確認ください。

## 開発

- ロジック単体テスト: `node tools/selftest.js`
- ビルド: GitHub Actions（windows-latest）がポータブル版 `OkibaBoard.exe` を生成します。
